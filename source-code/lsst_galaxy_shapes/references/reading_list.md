# Reading List

## Core Papers

### 1. Mandelbaum (2018) — Weak Lensing for Precision Cosmology
- **Citation:** ARA&A 56, 393-433
- **arXiv:** [1710.03235](https://arxiv.org/abs/1710.03235)
- **Topics:** Cosmic shear, galaxy-galaxy lensing, 3x2pt analysis, shear calibration requirements, photo-z calibration, intrinsic alignments
- **Why read:** Establishes the science case and systematic error budget for weak lensing with Stage IV surveys (LSST)

### 2. Mandelbaum et al. (2015) — GREAT3 Results I: Shear Estimation Systematics
- **Citation:** MNRAS 450, 2963
- **arXiv:** [1412.1825](https://arxiv.org/abs/1412.1825)
- **Topics:** KSB, shapelets, model-fitting, BFD, metacalibration; multiplicative/additive bias, noise bias, model bias, selection bias
- **Why read:** Comprehensive comparison of shear measurement methods and their failure modes

### 3. Lupton, Gunn & Szalay (1999) — A Modified Magnitude System
- **Citation:** AJ 118, 1406
- **arXiv:** [astro-ph/9903081](https://arxiv.org/abs/astro-ph/9903081)
- **Topics:** Asinh magnitudes ("luptitudes"), photometry of faint objects, handling negative fluxes
- **Why read:** Foundation for understanding how photometric catalogs report brightness; adopted by SDSS

### 4. Bosch et al. (2018) — The Hyper Suprime-Cam Software Pipeline
- **Citation:** PASJ 70, SP1, S5
- **arXiv:** [1705.06766](https://arxiv.org/abs/1705.06766)
- **Topics:** Full pipeline architecture (ISR → PSF modeling → calibration → coaddition → measurement), CModel photometry, deblending, brighter-fatter correction
- **Why read:** The HSC pipeline IS the LSST pipeline — this is the primary technical reference
